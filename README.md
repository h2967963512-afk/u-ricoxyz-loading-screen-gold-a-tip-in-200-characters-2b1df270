## The tip

> Tip: your agent read the entire codebase in four seconds and still has no idea what you meant by 'quick fix'.

109 characters, one line, one sentence. The agent did the impossible homework and still can't decode "quick fix" — a joke both the tired developer and the agent feel is about them.

## Run it

```sh
python3 main.py
```
